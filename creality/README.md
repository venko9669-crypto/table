# Плочи за Creality (маса 220 × 220 мм)

Отвори .3mf файловете в Creality Print (или Orca/Cura). Всяка плоча е
подредена и центрирана, частите са отделни обекти.

| Файл | Части | Запълване | Бележки |
|---|---|---|---|
| `plate1_links_outer.3mf` | 22 жълти + 2 end + 2 end_r | 40% gyroid | brim 5 мм (високи и тесни) |
| `plate2_links_inner.3mf` | 24 сини | 40% | |
| `plate3_shoes.3mf` | 4 обувчици | 25% gyroid | |
| `plate4_hub.3mf` | 1 вложка | 15% gyroid | |
| `plate5_mounts.3mf` | 2 mount + 2 mount_r | 50% gyroid | brim 8 мм (81 мм високи) |

Общо за всички: PETG, дюза 0.4, слой 0.2 мм, 4 стени, 5 горни/долни слоя,
без подпори. PETG: дюза 235-245 °C, маса 75-80 °C, вентилатор 30-50%.

Преди да пуснеш plate1 и plate2 изцяло - отпечатай по 1 жълто и 1 синьо
звено и пробвай с тръба.
